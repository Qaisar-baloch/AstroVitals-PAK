# 3D Anatomy Model Attribution

AstroVitals PAK uses the **Open Anatomy 3D** web-ready anatomical models and React viewer by MervinR07.

- Project: https://github.com/MervinR07/open-anatomy-3d
- Code licence: MIT
- Model licence: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Model sources: BodyParts3D (Database Center for Life Science / DBCLS), Human Reference Atlas (HuBMAP), and MakeHuman (CC0), as documented by the upstream project.
- Upstream attribution details: https://github.com/MervinR07/open-anatomy-3d/blob/main/ATTRIBUTION.md

The models are integrated into AstroVitals PAK with a custom dark medical theme, selected-region mapping, synthetic status pins, and a regional health-intelligence panel. These are project adaptations and UI additions; the underlying anatomical model is not claimed as original AstroVitals PAK work.

The model is an educational anatomical reference. It is not a medical device and must not be used for diagnosis, treatment, or surgical planning. AstroVitals PAK heatmap pins represent simulated demonstration status, not clinical findings.
